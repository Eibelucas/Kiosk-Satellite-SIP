Version 26.10.13 introduces a native SIP dialer for Kiosk Satellite. A floating phone button opens number entry, and outgoing calls connect directly through the Asterisk telephone server. The call view shows the destination, status, duration, mute, and hangup controls.

The Home Assistant OS add-on supports multiple SIP devices with separate extensions and passwords. Ringing targets can be selected for each external phone number. Answering on one device stops the others from ringing.

Additional changes:

- Centered phone, close, and delete icons.
- Number entry and the keypad are hidden during a call.
- Separate RTP reception and audio playback with a bounded PCM queue.
- Smaller Android buffer requests; actual call latency remains device- and network-dependent.

**Updating:** Update the plugin and add-on separately. When switching from the previous web phone launcher, enter the HAOS address, SIP port, extension, and device password once in the plugin. The regular plugin ID remains `kiosk-satellite-sip`. Add-on 26.10.12 remains compatible with one registration on extension 100; multiple devices require 26.10.13.

**Known limitations:** Shared microphone management with Voice Satellite, native contacts, DTMF, TLS/SRTP, hold, and transfer are not implemented. A measured comparison of end-to-end latency is not yet available. Automated checks cover SIP protocol behavior, audio buffering, package format, backend behavior, and multiple devices on Asterisk.
